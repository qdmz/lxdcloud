新手入门

三步拥有你的第一台云主机。

  1. 注册账号：打开 免费注册，填写用户名、邮箱和密码；如站点开启邮件验证，请到邮箱点击激活链接。
  2. 选购套餐：登录后进入「产品订购」，选择配置、系统镜像与计费周期（月付 / 季付 / 半年付 / 年付）。
  3. 支付并自动开通：在「我的订单」完成支付，系统自动创建实例，凭据显示在「我的实例」中，同时发送到邮箱。
忘记密码？在 找回密码 页输入注册邮箱即可重置。

购买与续费

支持余额、支付宝、微信支付，到期前可随时续费。

支付方式

  • 余额支付：余额充足时即时完成，并在收支记录中留下扣款流水。
  • 支付宝 / 微信：跳转在线支付，支付成功后订单自动变为「已支付」。

手动续费

  1. 进入「我的实例」，点击实例的「续费」。
  2. 选择续费周期（月付 / 季付 / 半年付 / 年付），弹窗会显示续费后的到期时间。
  3. 选择支付方式并确认，支付完成后到期时间自动顺延。

自动续费

在续费弹窗或实例卡片上打开「自动续费」。实例到期前 24 小时内，系统会按你选择的周期从余额自动扣费续期；若余额不足，会自动关闭自动续费并发送站内消息提醒，请充值后手动续费。

未支付的订单可在「我的订单」中继续支付或取消；已售罄或限购的套餐无法新购。

余额与充值

余额可用于新购、续费和自动续费。

  1. 登录后进入「账户余额」。
  2. 选择预设金额（¥10 ~ ¥500）或输入自定义金额（¥1 ~ ¥50000）。
  3. 选择支付宝或微信支付，支付成功后余额自动到账。

同一页面可查看全部收支记录：充值、消费、退款与调整，每条都显示订单号和变动后的余额。

实例管理

在用户中心或容器面板中自助管理。

容器面板

在「我的实例」中获取访问码，登录 容器面板，可查看 CPU / 内存 / 磁盘 / 流量监控，开关机、重启，以及使用浏览器 Web 终端。

重装系统

选择「重装系统」并挑选镜像即可。重装会清空系统盘数据，请提前做好快照或备份。

快照与备份

套餐包含的免费备份数在价格卡片中标明，可用于回滚到之前的状态。

SSH 登录

使用实例凭据中的 IP（或映射端口）登录，例如 ssh root@你的IP -p 端口。

网络与端口

IPv4 / IPv6、端口映射与反向代理。

  • 端口映射：在「端口映射」中把公网端口转发到实例内的端口（如 SSH 22、网站 80），数量以套餐为准。
  • 反向代理：在「反向代理」中绑定你的域名，即可通过 80 / 443 访问实例内的网站服务。
  • IPv6：套餐含 IPv6 时，实例创建后自动分配，可在实例详情中查看。
绑定域名前，请先把域名解析（A / AAAA 记录）指向平台提供的地址。

工单与通知

遇到问题，提交工单即可。

登录后进入「工单中心」新建工单，描述问题并附上实例名称，客服会在工单中回复。到期提醒、续费结果等重要通知会出现在「站内消息」并同步发送邮件。

常见问题

LXD 容器和 VPS 有什么区别？

LXD 是系统级容器，拥有完整的 Linux 用户空间，可以像 VPS 一样安装软件、运行服务，但共享宿主内核，启动更快、性能损耗更低。

支付成功了但订单还是待支付？

在线支付通常几秒内到账。若超过 5 分钟仍未更新，请刷新「我的订单」，仍未变化请提交工单并附上订单号。

实例到期后会怎样？

到期未续费的实例会被暂停，续费后即可恢复。建议开启自动续费并保持余额充足，避免服务中断。

余额可以提现吗？

余额用于平台内消费（新购、续费、自动续费）。如有特殊需求请提交工单。

可以升级配置吗？

目前可选购更高配置的新套餐并迁移数据，如需协助请提交工单。
