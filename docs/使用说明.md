# LXD Cloud 使用说明

本文档面向三种角色：**管理员**（管理后台）、**平台用户**（用户中心）、**容器用户**（容器面板）。三端功能对齐，均支持在线文件管理。

---

## 〇、界面通用操作（v1.1.0 起）

| 功能 | 说明 |
|---|---|
| 深色 / 浅色主题 | 顶栏（登录页为右上角）的 ☀ / ☾ 按钮切换；选择保存在浏览器本地，下次打开自动沿用；未手动选择时跟随系统主题 |
| 手机 / 平板 | 管理后台：点左上角 ☰ 打开侧边菜单，点遮罩或菜单项自动收起；桌面端 ☰ 可收起侧边栏（状态会记住）。用户中心：点右上角 ☰ 展开导航 |
| 表格 | 窄屏下表格可左右滑动查看全部列 |
| 一键复制 | IP、访问码、密钥等等宽显示的值旁边有「复制」按钮 |
| 危险操作确认 | 删除、重装、释放、取消订单、关闭工单等操作都会弹出确认框，`Esc` 取消 |
| 防重复提交 | 提交按钮在请求完成前显示加载状态并锁定，避免重复创建 / 重复下单 |
| 验证码 | 后端 `enable_captcha: false` 时登录页自动隐藏验证码输入框 |

## 一、管理后台（Admin）

### 1.1 登录

1. 访问 `http(s)://<你的域名>/admin/login.html`
2. 输入管理员用户名与密码（默认见后端 `config.yaml` 的 `admin` 段）
3. 若开启了验证码，按图片输入后登录

> 登录失败多次会触发 IP 锁定（默认 15 分钟），请勿频繁尝试。

### 1.2 主要功能

| 模块 | 功能 |
|---|---|
| 概览 Dashboard | 主机资源（CPU/内存/磁盘）、容器总数、在线状态 |
| 容器管理 | 创建/启停/删除容器、重装系统、修改配置、分配 IP、端口映射、反向代理、DNS、备注 |
| 在线文件管理 | 进入容器详情 → 点击「◈ 在线管理文件」→ 浏览/上传/下载/新建目录/重命名/删除 |
| 用户管理 | 创建/禁用/删除用户、重置 API Key、余额/配额 |
| 商品与订单 | 商品定价、订单列表、支付记录 |
| 模板管理 | 镜像模板同步、删除 |
| 存储池 | 存储池状态与配额 |
| IP 池 | IPv4/IPv6 地址池管理 |
| 端口映射 | 查看/分配/释放端口映射；**NAT 配置**（转发规则）、**端口范围**（可分配范围）、**网络 NAT**（lxdbr0 开关） |
| Nginx | 可视化生成容器站点反代配置 |
| 防火墙 | 容器防火墙规则（基于 opengfw 插件） |
| 任务中心 | 后台任务（创建/重装/删除）进度查看 |
| 品牌设置 | 站点名称、Logo、联系信息 |

### 1.3 容器详情页

容器详情页包含：启停/重启/重装、资源监控图表、IP 池、端口映射、反向代理、DNS、**在线管理文件**、**容器访问码（Hash）**（可复制与快捷打开容器面板）。

## 二、用户中心（User）

### 2.1 登录

1. 访问 `http(s)://<你的域名>/user/login.html`
2. 输入用户名与 **API Key**（密码字段填 API Key，管理员在后台用户管理中查看/重置）

### 2.2 主要功能

| 模块 | 功能 |
|---|---|
| 概览 | 实例数量、资源用量、订单统计 |
| 我的容器 | 容器列表、状态、IP；点击详情查看连接信息与资源监控；**强制同步**可从 LXD 重新拉取最新状态 |
| 在线文件管理 | 容器详情弹窗 →「在线管理文件」或「三方软件连接 SSH/SFTP」 |
| 端口映射 | 申请/管理自己的端口映射 |
| 反向代理 | 配置容器站点反代 |
| 模板 | 查看可用镜像模板 |
| 任务 | 查看自己的后台任务进度 |
| 个人资料 | 修改密码、查看 API Key |

### 2.3 连接容器

容器详情弹窗提供两种方式：
- **在线管理文件**：浏览器内直接操作文件（推荐，无需三方软件）
- **三方软件连接 SSH/SFTP**：显示公网 IP + 转发端口，可用 Xshell / WinSCP / FileZilla 连接

## 三、容器面板（Container）

### 3.1 登录

方式一：从管理后台或用户中心的容器详情页点击「快捷连接」（带 Hash 自动登录）。

方式二：手动访问 `container/login.html`，输入容器访问码 Hash。

> Hash 在管理后台/用户中心容器详情页的「容器访问码」行查看并复制。

### 3.2 主要功能

| 模块 | 功能 |
|---|---|
| 概览 | 容器资源监控（CPU/内存/磁盘/网络） |
| 在线文件管理 | 顶部「◈ 文件管理」按钮 → 浏览/上传/下载/新建目录/重命名/删除 |
| Web 终端 | 浏览器内在线 Shell（WebSocket + xterm.js） |
| IP 管理 | 查看/绑定容器 IP |
| 端口映射 | 管理自己的端口映射规则 |
| 反向代理 | 配置站点反代 |
| DNS | 设置容器 DNS |
| 系统操作 | 重装系统、重置密码、重启容器 |

## 四、在线文件管理操作指南

三端文件管理器界面与操作一致：

| 操作 | 方法 |
|---|---|
| 浏览目录 | 点击目录名进入；面包屑可快速返回上级/根目录 |
| 新建目录 | 点击「＋ 新建目录」→ 输入目录名（在当前路径下创建） |
| 上传 | 点击「上传」选择本地文件（可多选；建议单文件 < 100M，受 Nginx 限制） |
| 下载 | 点击文件行的下载按钮 |
| 重命名 | 点击文件/目录行的重命名按钮 → 输入新名称 |
| 删除 | 点击删除按钮 → 确认后删除（目录递归删除，请谨慎） |

注意事项：
- 路径必须为容器内绝对路径，禁止 `..` 跳转（后端强制校验）；
- 删除操作不可恢复，删除目录会递归清空；
- 上传大文件时请等待进度条完成后再离开页面。

## 五、常用 API（参考）

| 端 | 接口 | 说明 |
|---|---|---|
| Admin | `GET/POST /api/admin/containers/:name/files*` | 在线文件管理（list/download/upload/mkdir/delete/rename） |
| User | `GET/POST /api/user/containers/:name/files*` | 在线文件管理（同上，校验容器归属） |
| Container | `GET/POST /api/container/files*` | 在线文件管理（X-Container-Hash 鉴权） |
| Admin | `POST /api/admin/login` | 管理员登录（Cookie Session） |
| Public | `GET /api/public/site-info` | 站点开关（注册 / 支付 / 邮件 / 验证码是否启用） |
| Public | `GET /api/public/version`、`GET /healthz` | 版本号 / 健康检查 |
| Public | `POST /api/public/register` | 用户注册 |
| User | `GET /api/user/containers/:name/credential` | 获取容器访问码 Hash |

## 六、常见使用问题

| 问题 | 处理 |
|---|---|
| 忘记管理员密码 | 修改 `config.yaml` `admin.password` 后重启 lxdapi |
| 忘记用户 API Key | 管理员后台用户管理 → 重置 API Key |
| 忘记容器访问码 | 管理后台/用户中心容器详情 → 查看/重新生成访问码 |
| 文件管理提示 404 | 确认后端为含文件管理路由的最新版本（三端 `files` 路由） |
| 上传失败 413 | 调整 Nginx `client_max_body_size` |
| 管理员登录提示用户名或密码错误，但密码确实没错 | v1.1.0 起 `admin.password` 为空 / `CHANGE_ME` / `__ADMIN_PASS__` 等占位值时一律拒绝登录，请先在 `config.yaml` 设置真实密码（推荐 bcrypt 哈希） |
| 对接财务系统时 `/api/system/*` 返回 403「系统级 API 未启用」 | `system.security.api_hash` 未配置或仍为占位值，设置随机字符串后重启 |
| 激活 / 重置密码邮件里的链接域名不对 | 在 `config.yaml` 设置 `system.server.public_url`（如 `https://panel.example.com`） |
| 重启后台后所有人被登出 | `admin.session_secret` 未配置（每次启动随机生成），设置固定的 16 位以上随机串即可 |
